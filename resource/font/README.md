# 字体资源目录

此目录保留字体许可证，并作为运行时字体的落盘位置。两份 Noto Sans CJK OTF 文件不纳入插件仓库；插件加载和文本图片渲染前会确认默认字体可用。进程首次检查时校验文件大小与 SHA256，缺失或校验失败时从 [drdon1234/fonts 的 v1.0.0 Release](https://github.com/drdon1234/fonts/releases/tag/v1.0.0) 自动补全；字体就绪后只快速检查文件是否存在且大小正确，异常时重新完整校验。

运行时文件名固定为：

- `NotoSansCJKsc-Regular.otf`
- `NotoSansCJKsc-Bold.otf`

下载使用唯一 `.part` 临时文件，校验通过后原子替换目标文件；失败或取消产生的临时文件会被清理。

字体自动补全需要此目录可写并能访问 GitHub。补全失败时插件仍可加载，文本图片渲染会回退为原文本。

可通过 `ASTRBOT_MEDIA_PARSER_FONT` 环境变量指定优先使用的字体文件路径。未指定或该文件不可用时，按配置的字体族及可用字体回退；此设置不会跳过默认字体的检查与补全。
