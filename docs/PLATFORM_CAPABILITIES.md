# 平台能力与实测登记

本表按当前工作区的 32 个平台解析器登记文本、图片、视频、独立音频与评论能力；对应实现与配置已核对。接口细节与完整链接范围见[平台解析备忘](PARSER_METHOD_MEMO.md)，使用配置见[使用说明](../README.md)。本表记录实现事实、取数来源、失败证据和验证缺口，不把“未实现”写成“平台不可能”。

## 登记口径

- **已接入／已实现**：生产代码存在相应处理；是否本轮线上成功，另看该平台的实测表。**有条件／部分接入**：受内容形态、权限或返回字段限制。**未接入**：当前没有相应解析路径，不代表上游一定不可获取。
- **文本**包括标题、作者、正文或概况；**图片**区分正文原图、封面与生成的 README 截图；**视频**可含音轨；**独立音频**仅指写入 `audio_urls` 的结果，视频的 DASH 音轨不算独立音频。
- **评论**包括热门、普通回复、游戏评价与 Issue 讨论；红果分集弹幕单独标注来源。未开开关、空列表、业务失败、权限限制和未实现分别记录；零条不等于内容没有评论。
- **验证层级**依次为代码核对、真实解析入口、媒体首段探测、完整下载／解密／解码、AstrBot 实际发送。前一层通过不能代替后一层。
- **本轮条件**：2026-11-08（北京时间），本机直接联网、无用户登录 Cookie／Token、未配置代理；调用当前解析器 `parse()`，有评论参数时设置上限 3 条。全局最多 4 个样本并发，每例解析最多 65 秒。
- **媒体探测**：每例每种媒体只检查第一组第一候选，使用解析器返回的请求头及图片 TLS 设置，Range 请求只读最多 128 字节，核对 HTTP、类型与文件特征。HLS 只证明清单可读，DASH 只检查首个视频流，均不代表全片／音轨可下载。
- **本轮未做**：批量完整下载、解密与全片解码、Chromium README 截图、AstrBot 消息发送、全部平台的每一种内容子类型。未验证范围在各平台单独列明。
- **证据保存**：本地复测脚本与去凭据 JSON 位于根目录 `test/platform_capability_live.py`、`test/platform_capability_live.json`、`test/platform_comment_feasibility.py` 及同名 JSON，均被 `/test/` 忽略、不随仓库发布。本表保留日期、公开样本、结果与失败原因，脱离本地样本文件也能阅读。

首轮共实测 43 个公开样本，覆盖全部 32 个平台；39 个样本返回元数据，4 个样本解析失败。返回元数据的平台共 29 个；这项统计不等于所有媒体与评论均可用。各站样本表保留首轮记录，后续能力变化与生产入口结果另见“评论补充实测”和“评论接入验收”。
